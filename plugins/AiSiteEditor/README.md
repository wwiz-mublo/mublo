# AiSiteEditor plugin

Mublo의 블록·메뉴·게시판·테마 변경 계획을 검증하고 이후 미리보기·적용·복원을 제공하는 제품 중립 플러그인이다.

## 설치

`AiSiteEditor/` 디렉터리 전체를 대상 사이트의 `plugins/AiSiteEditor/`로 업로드한 뒤 관리자 확장 관리에서 활성화한다.

- 최소 코어: Mublo 1.11.0
- 프로토콜: `resources/protocol/version.json`
- 현재 단계에서는 설치된 코어 계약으로 실제 지원 가능한 도구만 capabilities에 노출한다.
