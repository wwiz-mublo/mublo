# 기여 가이드

기여 방법은 저장소 루트의 **[CONTRIBUTING.md](../../CONTRIBUTING.md)** 하나로 관리한다.
GitHub가 PR·이슈 화면에서 그 문서를 자동으로 안내하므로, 기준을 두 곳에 두면 반드시 어긋난다.

거기에 담긴 내용:

- 개발 환경 구성 (Dev Container 권장, 직접 구성 방법)
- 코드 스타일과 커밋 메시지 규칙
- Pull Request 절차와 체크리스트
- `CHANGELOG.md` 갱신 규칙
- 모듈 추가·변경 시 주의사항

## 관련 문서

- [테스트](testing.md) — 테스트 작성과 실행
- [아키텍처](architecture.md) — 코어 구조와 확장 지점
- [호환성 정책](../compatibility-policy.md) — 안정 API와 변경 규칙
