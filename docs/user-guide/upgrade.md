# 업그레이드

새 버전으로 파일을 교체한 뒤 해야 할 일을 정리합니다.

## 순서

1. **백업** — 데이터베이스와 `config/` 디렉터리를 먼저 백업하세요. 되돌릴 수단이 없으면 업그레이드하지 마세요.
2. **파일 교체** — 저장소 파일을 새 버전으로 덮어씁니다. `config/`, `storage/`, `public/storage/` 는 그대로 둡니다.
3. **마이그레이션 실행** — 관리자 → **시스템 → 마이그레이션** 에서 대기 중인 항목을 실행합니다.
4. **동작 확인** — 사이트 첫 화면과 관리자 로그인, 게시판 글 보기를 확인합니다.

> **3번을 건너뛰지 마세요.**
> 마이그레이션은 자동으로 적용되지 않습니다. 파일만 바꾸고 실행하지 않으면
> 새 코드가 아직 없는 컬럼을 읽어 화면이 깨질 수 있습니다.
> 대시보드에는 알림이 뜨지 않으므로 직접 확인해야 합니다.

## 대기 중인 마이그레이션 확인

관리자 → 시스템 → 마이그레이션 화면에서 Core·패키지·플러그인별로 실행 여부를 보여줍니다.
`대기` 개수가 0이 아니면 실행하세요.

비활성 상태인 패키지·플러그인의 마이그레이션은 목록에 나오지 않습니다.
나중에 활성화할 때 함께 적용됩니다.

## 문제가 생겼을 때

[문제 해결](troubleshooting.md) 문서를 참고하세요.
그래도 해결되지 않으면 백업으로 되돌린 뒤 문의해 주세요.
