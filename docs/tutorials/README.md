# 따라하기 튜토리얼

처음 Mublo를 설치한 분을 위한 실습 문서입니다. 이론 설명은 최소로 하고, 관리자 화면에서 그대로 따라 하면 결과가 나오도록 구성했습니다.

각 튜토리얼은 이전 것을 마쳤다고 가정합니다. 순서대로 진행하세요.

| 순서 | 튜토리얼 | 소요 시간 | 배우는 것 |
|------|----------|-----------|-----------|
| 0 | [시작 킷으로 5분 만에 사이트 골격 만들기](00-starter-kit.md) | 5분 | 설치 시(또는 대시보드에서) 시작 킷 선택, 게시판 연결 |
| 1 | [설치 직후 첫 30분](01-first-30-minutes.md) | 30분 | 관리자 접속, 사이트 이름 바꾸기, 메인 화면 문구 수정, 공지 올리기 |
| 2 | [메인 페이지를 블록으로 꾸미기](02-main-page-blocks.md) | 30분 | 행/열 만들기, 이미지·최신글 블록 배치, 스킨 선택 |
| 3 | [게시판 만들고 메뉴에 연결하기](03-new-board.md) | 20분 | 게시판 생성, 권한 설정, 메뉴 연결, 메인 노출 |

## 더 깊이 알고 싶다면

튜토리얼을 마친 뒤에는 [사용자 가이드](../user-guide/README.md)에서 각 기능의 전체 옵션을 확인할 수 있습니다. 스킨을 직접 만들고 싶다면 [블록 편집 개요](../block-editor-overview.md)부터 읽으세요.
