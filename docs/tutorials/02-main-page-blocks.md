# 튜토리얼 2 — 메인 페이지를 블록으로 꾸미기

[튜토리얼 1](01-first-30-minutes.md)을 마친 상태에서 시작합니다. 이번에는 메인 화면에 "이미지 + 공지사항 최신글" 2단 구역을 직접 만들어 봅니다.

블록의 원리는 간단합니다: **행(Row)** 을 만들고, 행을 **열(Column)** 로 나누고, 각 열에 **콘텐츠**(이미지, HTML, 게시판 최신글 등)를 담습니다.

```
┌───────────────────────────────────┐ ← 행 (메인화면 위치)
│ ┌────────────┐  ┌───────────────┐ │
│ │   이미지    │  │ 공지사항 최신글 │ │ ← 열 2개
│ └────────────┘  └───────────────┘ │
└───────────────────────────────────┘
```

## 1. 행 만들기

1. 관리자에서 **블록관리 > 블록행**으로 이동합니다.
2. **추가** 버튼을 누르고 다음처럼 설정합니다.

| 항목 | 값 |
|------|-----|
| 위치 | **메인화면** |
| 관리 제목 | `메인 이미지+공지` (관리자만 보는 이름입니다) |
| 너비 | 콘테이너 (중앙 정렬) |
| 열 개수 | **2** |

3. 저장하면 행 목록에 새 행이 나타납니다.

## 2. 왼쪽 열에 이미지 넣기

1. 방금 만든 행의 편집 화면에서 **1번 열**을 선택합니다.
2. 콘텐츠 타입에서 **이미지**를 고릅니다.
3. 이미지를 업로드하고, 클릭 시 이동할 링크를 넣고 싶으면 링크 URL을 입력합니다.
4. 저장합니다.

**확인**: 사이트 첫 화면을 새로고침하면 왼쪽에 이미지가 보입니다.

## 3. 오른쪽 열에 공지사항 최신글 넣기

1. 같은 행의 **2번 열**을 선택합니다.
2. 콘텐츠 타입에서 **게시판 최신글**(Board 제공)을 고릅니다.
   - 이 타입이 목록에 없다면 Board 패키지가 비활성 상태입니다. **시스템 > 확장관리**에서 Board를 활성화하세요.
3. 게시판 선택에서 **공지사항**을 고르고, 표시할 글 개수를 정합니다.
4. 스킨은 기본값 **basic**을 그대로 둡니다.
5. 저장합니다.

**확인**: 첫 화면 오른쪽에 튜토리얼 1에서 올린 공지가 보입니다. 새 공지를 올리면 자동으로 갱신됩니다 (블록 캐시는 글이 바뀌면 자동 무효화됩니다).

## 4. 블록에 제목 달기

열 설정에는 **제목** 영역이 있습니다.

- 제목 텍스트: `공지사항`
- "더보기" 링크: `/board/notice`

저장하면 블록 위에 제목과 더보기 링크가 표시됩니다.

## 5. 모양 다듬기 (선택)

행/열 설정에서 배경색, 패딩(여백), 높이를 PC와 모바일 각각 조절할 수 있습니다. 값을 바꾸고 저장한 뒤 첫 화면을 새로고침하며 비교해 보세요. 모바일 화면은 브라우저 폭을 줄이면 바로 확인할 수 있습니다.

## 여기까지 하면

- 행/열을 만들어 메인 화면에 새 구역을 추가할 수 있고
- 이미지·게시판 최신글 콘텐츠를 배치할 수 있고
- 제목과 여백으로 모양을 다듬을 수 있습니다.

전체 옵션(레이아웃 타입, 디스플레이 스타일, 슬라이드 등)은 [블록으로 페이지 만들기](../user-guide/block-page-builder.md)에서 확인하세요.
