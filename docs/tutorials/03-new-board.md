# 튜토리얼 3 — 게시판 만들고 메뉴에 연결하기

[튜토리얼 2](02-main-page-blocks.md)를 마친 상태에서 시작합니다. 이번에는 **갤러리 게시판**을 새로 만들어 상단 메뉴에 붙이고, 메인 화면에도 노출해 봅니다.

## 1. 게시판 만들기

1. 관리자에서 **게시판 > 게시판 설정 > 추가**로 이동합니다.
2. 다음처럼 입력합니다.

| 항목 | 값 |
|------|-----|
| 게시판명 | `갤러리` |
| 슬러그 | `gallery` (주소가 `/board/gallery`가 됩니다) |
| 그룹 | 기본 그룹 선택 |
| 스킨 | **gallery** |

3. 저장합니다.

**확인**: 주소창에 `/board/gallery`를 입력하면 빈 갤러리 게시판이 열립니다.

> 그룹은 게시판을 묶는 단위입니다. "커뮤니티" 같은 새 그룹을 만들고 싶으면 **게시판 > 게시판 그룹**에서 먼저 추가하세요.

## 2. 권한 정하기

게시판 설정의 권한 항목에서 누가 무엇을 할 수 있는지 레벨 값으로 정합니다.

| 값 | 의미 |
|----|------|
| 0 | 비회원도 허용 |
| 1 | 일반 회원부터 |
| 230 | 스태프부터 |
| 255 | 최고 관리자만 |

갤러리라면 이런 조합이 무난합니다: 목록/읽기 `0` (누구나 구경), 쓰기/댓글 `1` (회원만).

**확인**: 로그아웃한 상태(또는 시크릿 창)로 `/board/gallery`에 들어가면 목록은 보이지만 글쓰기 버튼이 없어야 합니다.

## 3. 상단 메뉴에 붙이기

게시판을 만들어도 메뉴에는 자동으로 나타나지 않습니다. 직접 연결합니다.

1. **메뉴관리**로 이동해 **메인** 메뉴를 선택합니다.
2. 메뉴 항목을 추가합니다.
   - 이름: `갤러리`
   - URL: `/board/gallery`
3. 정렬 순서를 조절하고 저장합니다.

**확인**: 사이트 첫 화면 상단 메뉴에 "갤러리"가 나타나고, 클릭하면 게시판으로 이동합니다.

## 4. 첫 글 올리고 메인에 노출하기

1. `/board/gallery`에서 이미지가 든 글을 하나 작성합니다.
2. 튜토리얼 2에서 배운 대로 **블록관리 > 블록행**에서 메인화면 위치에 행을 하나 더 만들고, 콘텐츠 타입 **게시판 최신글**에서 게시판을 **갤러리**로 선택합니다.

**확인**: 메인 화면에 갤러리 최신글이 썸네일과 함께 보입니다.

## 여기까지 하면

- 게시판을 만들고 스킨·권한을 정할 수 있고
- 메뉴에 연결해 방문자가 찾아갈 수 있게 했고
- 메인 화면에 게시판 콘텐츠를 노출할 수 있습니다.

카테고리, 비밀글, 리액션, 첨부파일 제한 같은 나머지 옵션은 [게시판 운영](../user-guide/board-usage.md)에서 확인하세요.
