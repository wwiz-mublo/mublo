# 튜토리얼 1 — 설치 직후 첫 30분

[설치](../user-guide/installation.md)를 마친 직후 상태에서 시작합니다. 이 튜토리얼을 마치면 사이트가 "설치된 기본 화면"에서 "내 사이트"로 바뀝니다.

준비물: 설치 시 만든 관리자 아이디/비밀번호.

## 1. 관리자 화면에 들어가기

브라우저에서 주소 끝에 `/admin`을 붙여 접속합니다.

```
https://내도메인/admin
```

설치 시 만든 관리자 계정으로 로그인하면 **대시보드**가 나옵니다. 시스템 정보와 회원 통계 위젯이 보이면 정상입니다.

> 로그인이 안 되면 [문제 해결](../user-guide/troubleshooting.md)을 확인하세요.

## 2. 사이트 이름 바꾸기

1. 왼쪽 메뉴에서 **환경설정**을 클릭합니다.
2. **기본 설정** 탭에서 다음을 수정합니다.
   - **사이트 제목** — 브라우저 탭과 검색 결과에 표시됩니다.
   - **부제목** — 사이트를 한 줄로 소개하는 문구입니다.
3. **저장**을 누릅니다.

**확인**: 새 탭으로 사이트 첫 화면(`https://내도메인/`)을 열어 브라우저 탭 제목이 바뀌었는지 봅니다.

## 3. 회사 정보 채우기

같은 환경설정 화면의 **회사 정보** 탭에서 회사명, 대표자, 연락처를 입력합니다. 이 값은 사이트 하단(푸터)에 표시됩니다.

## 4. 메인 화면 환영 문구를 내 것으로 바꾸기

설치하면 메인 화면에 기본 환영 블록이 하나 들어 있습니다. 이 내용을 직접 바꿔 봅니다.

1. 왼쪽 메뉴에서 **블록관리 > 블록행**으로 이동합니다.
2. 위치가 **메인화면**인 행이 하나 보입니다. 편집(수정) 버튼을 누릅니다.
3. 열 안의 콘텐츠가 **HTML 직접입력** 타입입니다. 에디터가 열리면 환영 문구를 지우고 원하는 인사말을 적습니다.
4. 저장합니다.

**확인**: 사이트 첫 화면을 새로고침하면 방금 적은 문구가 보입니다. 블록은 자동으로 캐싱되지만, 수정하면 캐시도 자동으로 갱신되므로 따로 할 일은 없습니다.

## 5. 첫 공지 올리기

설치하면 **공지사항** 게시판(스태프만 글쓰기)과 **자유게시판**(회원 글쓰기)이 만들어져 있습니다.

1. 사이트 첫 화면에서 상단 메뉴의 **공지사항**으로 이동하거나, 주소창에 `/board/notice`를 입력합니다.
2. 관리자로 로그인된 상태이므로 **글쓰기** 버튼이 보입니다.
3. "사이트를 열었습니다" 같은 첫 공지를 작성하고 등록합니다.

**확인**: 목록에 글이 보이고, 관리자 대시보드의 **최근 공지** 위젯에도 나타납니다.

## 여기까지 하면

- 사이트 제목·회사 정보가 내 것으로 바뀌었고
- 메인 화면 문구를 직접 수정할 수 있게 되었고
- 게시판에 글을 올릴 수 있습니다.

다음 튜토리얼에서 메인 페이지를 본격적으로 꾸며 봅니다.
