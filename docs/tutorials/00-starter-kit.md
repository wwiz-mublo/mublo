# 튜토리얼 0 — 시작 킷으로 5분 만에 사이트 골격 만들기

Mublo 는 사이트 성격별 **시작 킷**(회사 홈페이지형 / 커뮤니티형 / 쇼핑몰형)을 내장하고 있습니다. 킷을 적용하면 메인화면 골격(히어로·블록 배치·레이아웃)이 한 번에 만들어지고, 게시판만 만들어 연결하면 사이트가 완성됩니다.

## 방법 1 — 설치할 때 고르기 (권장)

웹 설치기의 **Step 3(도메인 설정)** 에 시작 킷 선택이 있습니다.

1. 미리보기를 보고 사이트 성격에 맞는 킷을 고릅니다. (직접 처음부터 만들고 싶다면 "기본"을 선택)
2. 설치를 마치고 사이트에 처음 접속하면, 킷이 필요로 하는 확장(게시판 등)이 자동으로 설치됩니다.
3. 메인 상단의 안내 박스가 다음 할 일을 알려줍니다.

**확인**: 설치 직후 메인화면에 히어로와 블록 골격이 보이고, 상단에 "시작 킷이 적용되었습니다" 안내가 있으면 성공입니다.

## 방법 2 — 이미 설치한 사이트에서

관리자 **대시보드**의 "시작 킷" 위젯 → **블록 킷에서 미리보고 적용하기**를 누르면 보관함에 등록된 시작 킷 3종이 보입니다. 원하는 킷을 적용하면 메인화면이 교체됩니다. 적용 전 미리보기를 지원하며, 적용 이력에서는 블록 킷이 바꾼 **레이아웃 설정만** 되돌릴 수 있습니다. 교체된 블록 행은 각 행의 변경 이력에서 복구합니다.

## 적용 후 할 일 — 안내 박스 순서대로

킷마다 메인 상단에 맞춤 안내가 표시됩니다. 공통 흐름은:

1. **게시판 만들기** — 게시판 > 게시판 설정에서 필요한 게시판 생성 (예: 공지, 질문답변, 자유게시판)
2. **블록에 연결** — 블록관리 > 블록행에서 각 열을 열어 만든 게시판 선택
3. **문구 바꾸기** — 히어로의 제목·버튼은 HTML 블록이라 자유롭게 수정 (이미지 없이 CSS 로만 만들어져 있습니다)
4. 쇼핑몰 킷이라면 상품 등록 — 상품·후기 블록은 자동 진열이라 등록만 하면 채워집니다
5. 설정이 끝나면 **안내 박스 행을 삭제** (블록관리에서)

## 자주 묻는 것

- **킷을 잘못 골랐어요** → 방법 2로 다른 킷을 적용하면 됩니다. 메인 골격만 바뀌고 게시글 데이터는 남습니다.
- **블록이 "등록된 글이 없습니다"로 비어 있어요** → 정상입니다. 게시판을 만들어 연결하고 글을 쓰면 채워집니다.
- **필요한 확장이 안 보여요** → 확장 관리에서 해당 패키지/플러그인이 활성화되어 있는지 확인하세요. 킷 선택 설치라면 첫 접속 시 자동 활성화됩니다.
