# Security Policy

**English** | [한국어](SECURITY.md)

Please do not report security vulnerabilities in a public issue.

## Reporting a vulnerability

Use either of these private channels:

- email **admin@wwiz.kr**;
- a private GitHub Security Advisory for this repository.

Include, when possible:

- reproduction steps;
- affected components and versions;
- expected impact and a realistic abuse scenario;
- any temporary mitigation you have identified.

Do not include real production credentials, tokens, private URLs, or personal data in a public issue.

## Scope

This policy covers the repository's Core (`src/`), Packages (`packages/Board`, `packages/Shop`), and bundled Plugins (`plugins/`).

## Response targets

| Stage | Target |
|---|---|
| Acknowledge the report | Within 3 business days |
| Reproduce and assess severity | Within 7 days after acknowledgement |
| Publish a fix | Critical/High: within 14 days; Medium/Low: in the next scheduled release |

Details may be withheld until a fix or mitigation is available. The reporter will be notified when remediation is complete.
